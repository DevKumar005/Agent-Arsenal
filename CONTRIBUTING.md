# 💬 Requests & Feedback (Pull Requests Closed)

> **Note:** This repository is maintained directly by the author. **Pull Requests are not accepted at this time.**

If you'd like to suggest a new skill, report an outdated install command, or request a feature:

1. **Open a GitHub Issue** using the [Skill / Feature Request](.github/ISSUE_TEMPLATE/skill-request.md) template.
2. Share:
   - The skill/repo URL
   - What it does and which platforms it supports
   - Why it's useful (and when *not* to use it)
3. The author will review, test, and add it to the hub if it fits.
